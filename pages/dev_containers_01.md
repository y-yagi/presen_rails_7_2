# Development containers configuration for applications

* 新規にアプリケーションを作成した際に、[Development Containers](https://containers.dev/)用のファイルを生成するよう変更
* そもそもDevelopment Containersとは
  * 開発環境をDockerコンテナとしてビルドし、ソースコードを管理・共有できるようにするための仕様
  * 前身はMicrosoft社の「VSCode Remote - Container」で、これをOSSにしたもの
  * GitHub Codespacesでも使用されている
